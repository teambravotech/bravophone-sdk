Bravophone SDK — teste local

Esta página é o "site do cliente". Carrega o build UMD de dist/ por <script>, igual ao uso por CDN. O webphone roda num iframe de outra origem (porta 5174), então o teste é cross-origin de verdade.

Qual webphone carregar

O real carrega os 932 KB do popup.js intactos — é o seu UI. Precisa de rede/CORS para logar; sem isso a tela renderiza mas não registra. O mock não depende de nada.

Telefonia
Janela
ver todos os estados →

Sem moldura, arraste pelo próprio webphone (qualquer área que não seja botão/campo). Redimensione por qualquer borda ou canto. A posição persiste ao recarregar.
Feche a janela para ver a aba lateral: passe o mouse para revelar a alça de pontinhos, arraste-a na vertical, ou clique para reabrir.

Encaixe (dock)

Arrastando, o perímetro inteiro encaixa: laterais = altura cheia; borda de baixo = metade inferior; topo = maximizar (ou metade superior, com dockTop:'top-half'); os quatro cantos = meia tela. A prévia azul mostra o encaixe antes de soltar; arraste de volta para o meio para desencaixar.
Redimensionando: ao chegar a ~32px de uma borda, a janela completa sozinha até ela.
