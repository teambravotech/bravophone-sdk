Bravophone SDK —

O webphone completo dentro de qualquer página. Cada botão executa uma chamada real da API e mostra o código que rodou, com os valores dos campos já resolvidos. O texto é lido do corpo da própria função — não existe um segundo lugar onde o exemplo possa divergir do que acontece. Use code em cada bloco para ver o grupo inteiro de uma vez.

Instalação

Cole inline, não como arquivo externo — um arquivo externo teria o mesmo problema de cache que este trecho existe para evitar.
